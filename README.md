# Git Reset Practice

A beginner-friendly repository created to practise Git and GitHub commands through hands-on exercises.

## About This Project

This is my personal Git practice repository. I use it to understand version control, manage changes, track project history, and learn how developers collaborate using Git.

## Topics Covered

- Git initialization
- Git commits
- Git reset
- Git stash
- Git log
- Git show
- Git diff

## Tools Used

- Git
- GitHub
- Visual Studio Code

## Learning Goals

- Understand how Git tracks changes.
- Learn how to manage commits and project history.
- Practise recovering and managing changes safely.
- Build confidence with Git and GitHub workflows.
